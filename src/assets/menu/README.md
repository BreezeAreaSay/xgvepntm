# Фотографии блюд

Положите файлы сюда. Имя файла = `id` блюда из `src/data/menu.ts`.
Больше ничего делать не нужно — фото подхватится автоматически.

| Файл | Блюдо |
|---|---|
| `classic-spicy.jpg` | Классический пряно-острый суп |
| `tomato.jpg` | Солнечный томатный суп |
| `mushroom.jpg` | Нежный грибной суп |
| `tom-yam.jpg` | Суп Том Ям |
| `hot-sour.jpg` | Горячий кисло-острый суп |
| `mao-kai.jpg` | Мао Кай на говяжьем жире |
| `mala-ban.jpg` | Мала Бан — ароматный микс в соусе |
| `mala-syangu.jpg` | Мала Сянгу — обжаренный на воке |
| `rice.jpg` | Китайский белый рис на пару |

Подойдут `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`.

## Требования к исходникам

- **Ширина от 1200 px.** Astro сам нарежет меньшие размеры, но увеличить
  маленькую картинку не сможет — на экранах с высокой плотностью будет мыло.
- **Пропорции близко к 4:3.** Карточка обрезает по центру (`object-fit: cover`),
  так что вертикальные фото потеряют края.
- **Сжимать заранее не нужно.** Кладите исходники как есть: пережатие
  в AVIF и WebP, нарезка размеров и кеширующие хеши — работа сборки.
  Готовые файлы окажутся в `dist/_astro/`.

Оптимизировать вручную имеет смысл только если исходники огромные
(20+ МБ каждый) — тогда сборка будет заметно дольше.
