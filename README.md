# Джан Лян Малатан — сайт заведения

Одностраничный сайт: меню, доставка через Яндекс Еду, обезличенные отзывы,
контакты с картой и интерактивная 3D-миска малатана.

**Новая сессия или новый разработчик — начните с [`HANDOFF.md`](./HANDOFF.md).**

**Прежде чем публиковать — заполните данные из [`DATA-NEEDED.md`](./DATA-NEEDED.md).**

## Стек

| Что | Чем | Почему |
|---|---|---|
| Каркас | [Astro](https://astro.build) 7 | Отдаёт ноль JavaScript по умолчанию; собирается в статику |
| Язык | TypeScript (`strict`) | Ошибки ловятся в редакторе, а не у гостя на телефоне |
| 3D | [Three.js](https://threejs.org) | Единственный интерактивный остров, грузится лениво |
| Бэкенд | нет | Брони нет, форм нет — сохранять нечего |

Брони на сайте нет сознательно: в заведении свободная посадка.

## Команды

```bash
npm install        # один раз
npm run dev        # локально: http://localhost:4321
npm run check      # проверка типов, должно быть 0 errors
npm run build      # сборка в dist/
npm run preview    # посмотреть собранную версию
```

## Структура

```
src/
├── data/           ← правите здесь: меню, отзывы, контакты
│   ├── menu.ts
│   ├── reviews.ts
│   └── contacts.ts
├── components/     ← разделы страницы
│   ├── Hero.astro       — первый экран + 3D
│   ├── SoupScene.astro  — остров с ленивой загрузкой Three.js
│   ├── Menu.astro       — меню из data/menu.ts
│   ├── Delivery.astro   — Яндекс Еда
│   ├── Reviews.astro    — отзывы + ссылка на Яндекс Карты
│   └── Contacts.astro   — контакты + карта
├── scripts/soup.ts ← 3D-сцена, собрана из примитивов
├── styles/global.css ← дизайн-токены: цвета, шрифты, отступы
└── pages/index.astro ← сборка страницы из компонентов
```

Данные отделены от вёрстки специально: чтобы поменять цену, в разметку
лезть не нужно.

## Вес и скорость

Замеры реальной сборки (gzip):

| Файл | Вес | Когда грузится |
|---|---|---|
| `index.html` | ~3,9 КБ | сразу |
| CSS | ~3,1 КБ | сразу |
| Загрузчик 3D | ~1,1 КБ | сразу |
| **Итого первая загрузка** | **~8 КБ** | |
| Three.js + сцена | ~134 КБ | только при простое браузера |

Три приёма, которые дают этот результат:

1. **3D не в критическом пути.** Сначала показывается CSS-заглушка миски —
   она весит ноль. Three.js подтягивается динамическим `import()` и только
   когда браузер закончил первую отрисовку (`requestIdleCallback`).
2. **Экономный режим.** При включённой экономии трафика или на 2G/3G
   3D не загружается вообще — 134 КБ ради декорации не стоят пяти секунд
   ожидания меню.
3. **Рендер по требованию.** Кадры не рисуются, когда миска вне экрана или
   вкладка неактивна. При `prefers-reduced-motion` рисуется один статичный кадр.

3D-модели нет как файла: миска, ингредиенты и пар собраны процедурно
из примитивов Three.js. Захотите фотореализм — замените `createBowl()`
в `src/scripts/soup.ts` на `GLTFLoader` со сжатой моделью (Draco + KTX2).

## Деплой на reg.ru

Сайт статический, поэтому подойдёт **самый дешёвый тариф виртуального
хостинга**. VPS, Docker и Node.js на сервере не нужны.

1. В `astro.config.mjs` заменить `site: 'https://example.ru'` на свой домен.
2. Собрать: `npm run build` — результат в `dist/`.
3. Залить **содержимое** `dist/` (не саму папку) в корень сайта на хостинге —
   обычно это `public_html` или `www/ваш-домен.ru`. Подойдёт FileZilla по SFTP
   или файловый менеджер в панели управления.
4. В панели reg.ru привязать домен и включить бесплатный сертификат
   Let's Encrypt, чтобы сайт открывался по `https://`.

`node_modules/` и `dist/` на сервер не нужны и в git не попадают — см. `.gitignore`.
