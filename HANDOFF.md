# Передача проекта в новую сессию

Читайте этот файл первым. Здесь состояние проекта, команды и решения,
которые уже приняты — чтобы не переделывать сделанное.

## Что это

Одностраничный сайт заведения **ДЖАН ЛЯН МАЛАТАН** (张亮麻辣烫, франшиза
в России). Владелец сайта — новичок в разработке, проект одновременно
учебный: объясняйте решения, а не только выдавайте код.

Разделы страницы: первый экран с интерактивной 3D-миской, меню,
доставка через Яндекс Еду, обезличенные отзывы, контакты с картой.

**Брони на сайте нет и не должно быть** — в заведении свободная посадка.
Формы отсутствуют, бэкенда нет, сборка полностью статическая.

## Быстрый старт

```bash
git clone https://github.com/BreezeAreaSay/xgvepntm.git
cd xgvepntm
git checkout malatan-front
npm install
```

Проверено на Node 22 и npm 10. Astro требует Node 18.20+, 20.3+ или 22+.

```bash
npm run dev      # локальный сервер: http://localhost:4321
npm run check    # проверка типов — должно быть ровно 0 errors
npm run build    # сборка в dist/
npm run preview  # посмотреть собранную версию
```

`npm run check` перед каждым коммитом. Сейчас 0 ошибок, держите так.

## Стек и принятые решения

| Что | Чем | Почему именно так |
|---|---|---|
| Каркас | Astro 7 | Отдаёт ноль JS по умолчанию, собирается в статику |
| Язык | TypeScript, `strict: true` | Ошибки в редакторе, а не у гостя в браузере |
| 3D | Three.js 0.186 | Единственный интерактивный остров |
| Бэкенд | нет | Брони и форм нет — сохранять нечего |
| Хостинг | виртуальный на reg.ru | Статика, VPS и Docker не нужны |

Флаги `noUncheckedIndexedAccess` и `exactOptionalPropertyTypes` выключены
намеренно: владелец учится, они дают много шума при малой пользе. Не включайте
без запроса.

### 3D-сцена: не заменяйте на GLB без причины

`src/scripts/soup.ts` собирает миску, ингредиенты и пар **процедурно из
примитивов Three.js**. Файла модели нет вообще — это осознанное решение:
GLB из генератора весил бы мегабайты. Если понадобится фотореализм, меняйте
`createBowl()` на `GLTFLoader` со сжатой моделью (Draco + KTX2), интерфейс
модуля при этом сохраняйте.

Что уже сделано для скорости, не ломайте:

- сцена подключается динамическим `import()` **после** первой отрисовки
  (`requestIdleCallback`), а не в критическом пути;
- при `saveData` или сети 2G/3G Three.js **не загружается вообще**;
- кадры не рисуются, когда канвас вне экрана или вкладка неактивна;
- при `prefers-reduced-motion` рисуется один статичный кадр.

## ⚠️ Чего делать НЕЛЬЗЯ

Два запрета, они важнее скорости и красоты.

**1. Не придумывать отзывы.** `src/data/reviews.ts` пуст намеренно.
Выдуманный отзыв, поданный как настоящий, — обман гостя и репутационный
риск для заведения. Брать только реальные со страницы в Яндекс Картах,
убирать имена и личные детали, смысл не менять (сокращать можно,
переписывать нельзя), период указывать как «месяц год». Оставлять и
умеренно критичные: страница из одних пятёрок читается как накрутка.

**2. Не придумывать контакты.** Адрес, телефон, часы работы в
`src/data/contacts.ts` — заглушки (`TODO = null`). Неверный адрес отправит
гостя не туда. Заполнять только тем, что подтвердил владелец.

Компоненты сами скрывают незаполненные блоки и показывают пунктирные
подсказки, так что сайт не сломан. Это штатное состояние, а не баг.

## Что нужно сделать

### Фотографии блюд

Владелец подтвердил, что фото использовать можно. Предыдущая сессия не
смогла их добавить: изображения приходили как картинки для просмотра, без
доступа к файлам. Вырезать из макета меню тоже не вариант — там каждое фото
примерно 300×230 px, а карточке нужно ~900 px, будет мыло.

Вставка настроена по соглашению об именах — **код править не нужно**:

```
src/assets/menu/classic-spicy.jpg  →  фото у «Классического пряно-острого супа»
```

Имя файла = `id` блюда из `menu.ts`. Полный список из девяти имён и
требования к исходникам — в `src/assets/menu/README.md`.

Исходники кладите как есть, **не сжимайте заранее**: `<Picture>` сам
пережмёт в AVIF и WebP, нарежет под 160/320/560 px и добавит хеши для
кеширования. Требование одно — ширина от 1200 px, пропорции близко к 4:3.

### Ссылки и данные (для этого и нужен интернет)

Заполнить в `src/data/contacts.ts`:

| Поле | Где взять |
|---|---|
| `yandexEdaUrl` | Страница заведения в Яндекс Еде |
| `yandexMapsUrl` | Карточка в Яндекс Картах → «Поделиться» |
| `yandexMapEmbedUrl` | yandex.ru/map-constructor → точка → «Получить код» → только адрес из `src="..."` |
| `city`, `address`, `phone`, `workingHours` | **Только от владельца**, не из поиска |

Отзывы — из Яндекс Карт по правилам выше, в `src/data/reviews.ts`.

### Перед публикацией

1. В `astro.config.mjs` заменить `site: 'https://example.ru'` на реальный домен.
2. Сверить цены с актуальными в зале — в коде они перенесены с фото меню.
3. Согласовать формулировку про публичную оферту в футере.
4. Прогнать Lighthouse на мобильном профиле.

## Деплой на reg.ru

Сайт статический, годится самый дешёвый тариф виртуального хостинга.

1. `npm run build` — результат в `dist/`.
2. Залить **содержимое** `dist/` (не саму папку) в корень сайта —
   обычно `public_html` или `www/домен.ru`. Подойдёт SFTP или файловый
   менеджер в панели.
3. В панели привязать домен и включить сертификат Let's Encrypt.

`node_modules/` и `dist/` на сервер не нужны и в git не попадают.
